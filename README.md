# 온보딩 대시보드

온보딩 담당 HR의 업무 대시보드입니다. 기획 과정(업무 흐름 → 불편한 점 → 필요한 기능 → 데이터 원천)은 [PLANNING.md](PLANNING.md)에 있습니다.

빌드가 필요 없는 정적 웹앱입니다. 폴더를 그대로 배포하면 됩니다.

## 화면
| 메뉴 | 하는 일 |
|---|---|
| 오늘 할 일 | 데이터 기준일 확인, **연락할 곳별로 묶은 할 일**과 요청 문구 복사, 2주 안 입사자 준비율, 법정·규정 기한(4대보험 신고, 법정교육, 수습 평가), 설문 발송 대기, 관심 필요 입사자 |
| 입사 준비 현황판 | 입사자 × 준비 항목 체크표. 칸을 눌러 완료 표시, 항목별 미완료 명단 복사(IT·총무 요청용), 입사자별 서류 안내 문구 |
| 입사자 | 목록·검색·필터, 상세(할 일, 설문 응답, 수습 종료일), 퇴사·입사 취소 |
| 설문 | 설문 만들기(문항·대상·시점), 보낼 대상 자동 선정, 개인 링크 발송, 응답 화면, 결과(분포, eNPS, 서술형) |
| 데이터 가져오기 | 채용 시스템 합격자 명단, 인사 시스템 인사 기본 정보, LMS 수료 현황, 구글 폼 응답을 **엑셀 그대로** 올리기. 열 자동 매칭 → 바뀌는 내용 미리 보기 → 반영 |
| 체크리스트 설정 | 준비 항목, 담당, 기한, 수습 기간 |

## 데이터
- 처음 열면 **오늘 날짜를 기준으로** 입사자 35명의 더미 데이터가 만들어집니다.
- 가져오기 화면마다 **샘플 엑셀 받기**가 있습니다. 샘플 엑셀은 화면 속 데이터와 맞물리게 그 자리에서 만들어집니다. 그래서 올리면 새 입사자 추가, 입사일 변경, 입사 포기, 퇴직, 교육 수료, 설문 응답이 실제로 반영됩니다.
- 데이터는 방문자 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html`, `css/app.css`, `css/v3.css` | 화면 틀과 스타일 |
| `js/data.js` | 데이터 구조, 기한·상태 규칙, 기본 체크리스트와 설문, 더미 데이터, 샘플 엑셀 생성 |
| `js/app.js` | 화면과 동작 (가져오기 매칭, 설문 발송·응답 포함) |
| 외부 라이브러리 | SheetJS(엑셀 읽기·쓰기), Pretendard 글꼴 (CDN) |
| `tools/serve.js` | 로컬 미리보기 (`node tools/serve.js` → http://localhost:5190). 배포에서는 빠집니다 |

## 배포 (Vercel)
컴퓨터 이름이 한글이면 `vercel login`이 실패합니다. 이때는 https://vercel.com/account/tokens 에서 토큰을 만든 뒤 이 폴더에서 아래 명령을 실행합니다.

```
npx.cmd vercel deploy --prod --yes --token 토큰값
```
